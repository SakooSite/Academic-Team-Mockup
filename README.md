# ระบบบริหารจัดการงานวิชาการภายในโรงเรียน

Development of Academic Management System for Schools

เปิดดูเว็บได้ที่ https://sakoosite.github.io/Academic-Team-Mockup/

โครงงานนี้เป็นต้นแบบหน้าจอของระบบงานวิชาการสำหรับโรงเรียนมัธยม ครอบคลุม 4 ส่วน คือ หลักสูตร ตารางสอน การบันทึกคะแนนและเช็คชื่อ และรายงานวิชาการ ข้อมูลทุกหน้าเป็นข้อมูลจำลอง ยังไม่ได้เชื่อมกับฐานข้อมูลจริง

## เทคโนโลยีที่ใช้

ระบบเขียนด้วย HTML, CSS และ JavaScript ล้วน ไม่มีขั้นตอน build และไม่มี backend หน้าเว็บโหลด Tailwind CSS และฟอนต์จาก CDN จึงต้องต่ออินเทอร์เน็ตตอนเปิด หน้ารายงานใช้ Chart.js ที่เก็บไว้ในโฟลเดอร์ `assets/` ส่วนหน้าตารางสอนใช้ SheetJS จาก CDN สำหรับนำเข้าและส่งออกไฟล์ Excel

ข้อมูลจำลองสร้างจากไฟล์ JavaScript ตอนเปิดหน้าครั้งแรก การแก้ไขทุกอย่างเก็บไว้ใน localStorage ของเบราว์เซอร์เครื่องนั้น ปิดแล้วเปิดใหม่ข้อมูลยังอยู่

## วิธีเปิด

เปิดจากลิงก์ https://sakoosite.github.io/Academic-Team-Mockup/ ได้ทันที ไม่ต้องติดตั้งอะไรเพิ่ม

ถ้าต้องการรันในเครื่อง ให้เปิด terminal ที่โฟลเดอร์นี้ แล้วรันคำสั่งนี้

```bash
python -m http.server 8765
```

จากนั้นเข้า `http://localhost:8765/` หน้าแรกจะพาไปที่หน้าภาพรวมงานวิชาการ ถ้าใช้ VS Code จะเปิดด้วยส่วนเสริม Live Server แทนก็ได้

## การใช้งานเบื้องต้น

ระบบไม่มีหน้าล็อกอิน มุมมองมี 2 บทบาท คือ admin ซึ่งหมายถึงครูฝ่ายวิชาการ และครูผู้สอน สลับบทบาทได้จากปุ่มใน sidebar ด้านซ้าย เมนูใน sidebar จะเปลี่ยนตามบทบาทที่เลือก

ปุ่มรีเซ็ตข้อมูลใน sidebar ใช้ล้างข้อมูลที่แก้ไขไว้ทั้งหมด แล้วกลับไปใช้ข้อมูลจำลองชุดเริ่มต้น

## โครงสร้างโฟลเดอร์

```
index.html     หน้าแรก พาไปที่ reports/overview.html
shared/        sidebar และ header ที่ทุกหน้าใช้ร่วมกัน
assets/        สคริปต์และไลบรารีของหน้ารายงาน
curriculum/    โมดูลหลักสูตร 3 หน้า
timetable/     โมดูลตารางสอน 4 หน้า
grading/       โมดูลบันทึกคะแนนและเช็คชื่อ 2 หน้า
reports/       โมดูลรายงานวิชาการ 16 หน้า
```

ทุกโฟลเดอร์มีไฟล์ README.md ของตัวเอง อธิบายว่าแต่ละไฟล์คือหน้าอะไรหรือทำหน้าที่อะไร

| โฟลเดอร์ | เนื้อหา |
|---|---|
| [shared/](shared/) | `academic-layout.js` สร้าง sidebar, header, ปุ่มสลับบทบาท และปุ่มรีเซ็ตข้อมูลให้ทุกหน้า |
| [assets/](assets/) | ข้อมูลจำลองและสคริปต์ของหน้ารายงาน 5 หน้า กับไลบรารี Chart.js |
| [curriculum/](curriculum/) | จัดการหลักสูตร โครงสร้างหลักสูตร และรายวิชา |
| [timetable/](timetable/) | จัดตารางสอน อนุมัติคำขอ ตารางสอนของครู และเวลาไม่ว่างของครู |
| [grading/](grading/) | ครูกรอกคะแนนและเช็คชื่อรายคาบ ครูฝ่ายวิชาการตรวจ อนุมัติ หรือตีกลับผลการเรียน |
| [reports/](reports/) | หน้าภาพรวม รายงานสอบซ่อม จัดอันดับคะแนน ผลการเรียน การเข้าเรียน และระเบียนสะสม |

## ข้อจำกัด

- เป็นต้นแบบสำหรับสาธิตหน้าจอและขั้นตอนการทำงาน ยังไม่มีฐานข้อมูลและระบบสิทธิ์จริง
- การจำกัดสิทธิ์มีแค่ระดับเมนู ถ้าพิมพ์ URL ของหน้าที่ไม่อยู่ในเมนูของบทบาทนั้นก็ยังเปิดได้
- ข้อมูลเก็บแยกตามเบราว์เซอร์ คนละเครื่องหรือคนละเบราว์เซอร์จะเห็นข้อมูลไม่ตรงกัน
- ปุ่มส่งออกและพิมพ์ในหน้ารายงานบางหน้ายังเป็นหน้าจอตัวอย่าง กดแล้วระบบแจ้งว่ายังไม่เชื่อมต่อการทำงานจริง
