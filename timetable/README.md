# timetable

โมดูลตารางสอน มี 4 หน้า ทุกหน้าใช้ข้อมูลชุดเดียวกันที่เก็บใน localStorage

| หน้า | บทบาท | เนื้อหา |
|---|---|---|
| `timetable.html` | admin | จัดตารางสอนเอง หรือกดจัดอัตโนมัติ ระบบตรวจคาบที่ชนกันให้ ล็อกคาบที่ไม่ต้องการให้ย้าย คัดลอกจากฉบับเดิม นำเข้าและส่งออกไฟล์ Excel และเผยแพร่ตารางสอน |
| `timetable-approvals.html` | admin | อนุมัติหรือปฏิเสธคำร้องของครู เช่น ขอย้ายคาบ ขอสลับคาบ หรือขอใช้ห้อง |
| `my-timetable.html` | ครู | ดูตารางสอนฉบับที่เผยแพร่แล้ว ดูรายละเอียดคาบ และยื่นคำร้องขอเปลี่ยนการจัด |
| `teacher-profile.html` | ครู | ดูโปรไฟล์ และกำหนดช่วงเวลาที่ไม่ว่างสอน |

| ไฟล์สคริปต์ | หน้าที่ |
|---|---|
| `timetable-core.js` | ส่วนกลางของทั้ง 4 หน้า อ่านและบันทึกข้อมูล จัดการฉบับของตารางสอน และตรวจการชนกันของคาบ |
| `timetable-data.js` | สร้างข้อมูลจำลองเริ่มต้น ได้แก่ หลักสูตร ครู ห้องเรียน และคำร้อง |

ตารางสอนแต่ละภาคเรียนมีได้หลายฉบับ ฉบับร่างแก้ไขได้ ฉบับที่เผยแพร่แล้วแก้ไม่ได้ ถ้าต้องการเปลี่ยนต้องสร้างฉบับใหม่
