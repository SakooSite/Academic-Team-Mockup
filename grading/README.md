# grading

โมดูลบันทึกคะแนนและเช็คชื่อ มี 2 หน้า แต่ละหน้าเปลี่ยนมุมมองย่อยด้วย hash ใน URL เช่น `scores.html#/followup` ทั้งสองหน้าใช้ข้อมูลชุดเดียวกัน

## หน้า

`scores.html` หน้าบันทึกคะแนน มุมมองขึ้นกับบทบาท

- ครูผู้สอน ดูรายวิชาของตน ตั้งโครงสร้างคะแนน กรอกคะแนน ดูผลการเรียน และส่งผลให้ฝ่ายวิชาการตรวจ มีหน้านักเรียนที่ต้องติดตาม บันทึกผลสอบซ่อม และชุมนุมของฉัน
- ครูฝ่ายวิชาการ ดูภาพรวมทั้งโรงเรียน ตรวจผลการเรียนในกล่องงาน อนุมัติ หรือตีกลับพร้อมปักหมุดข้อสังเกต แก้คะแนนเองไม่ได้

`attendance.html` หน้าเช็คชื่อรายคาบสำหรับครู แสดงคาบวันนี้ ห้องที่สอน และห้องประจำชั้น เวลาเรียนที่บันทึกในหน้านี้ใช้คำนวณสิทธิ์สอบในหน้าบันทึกคะแนน

## ไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `grading-layout.js` | เชื่อมทั้งสองหน้าเข้ากับ sidebar และ header กลางใน `shared/` |
| `assets/js/data.js` | ค่าคงที่ของโมดูล ได้แก่ ผู้ใช้ รายวิชา เกณฑ์เกรด คุณลักษณะอันพึงประสงค์ ตัวชี้วัด และการมอบหมายครู หน้ารายงานบางหน้าก็อ่านไฟล์นี้ |
| `assets/js/seed.js` | สร้างข้อมูลจำลองทั้งโรงเรียน ชั้น ม.1 ถึง ม.3 ชั้นละ 3 ห้อง 9 วิชา |
| `assets/js/app.js` | มุมมองครูผู้สอน การคำนวณผลการเรียน ตารางกรอกคะแนน และการส่งผล |
| `assets/js/academic.js` | มุมมองครูฝ่ายวิชาการ ภาพรวม กล่องงาน การตรวจ หมุดข้อสังเกต และรายงาน |
| `assets/js/remedial.js` | บันทึกผลสอบซ่อม |
| `assets/js/clubs.js` | บันทึกผลชุมนุม ผ หรือ มผ ครูกรอกเวลาเข้าร่วมเองโดยไม่เช็คชื่อรายคาบ |
| `assets/js/attendance.js` | หน้าเช็คชื่อรายคาบ |
| `assets/js/attendance-core.js` | ตารางสอนจำลองและการคำนวณเปอร์เซ็นต์เวลาเรียน ใช้ร่วมกันทั้งสองหน้า |
| `assets/css/style.css` | สไตล์หลักของหน้าบันทึกคะแนน รองรับจอมือถือและการสั่งพิมพ์ |
| `assets/css/theme.css`, `assets/css/type-scale.css` | สีและขนาดตัวอักษร |
| `assets/css/attendance.css` | สไตล์ของหน้าเช็คชื่อ |
