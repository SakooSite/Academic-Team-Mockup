# shared

ไฟล์ที่ทุกหน้าในระบบใช้ร่วมกัน

| ไฟล์ | หน้าที่ |
|---|---|
| `academic-layout.js` | สร้าง sidebar และ header ของทุกหน้า มีเมนูแยกตามบทบาท ปุ่มสลับบทบาท admin กับครู ปุ่มรีเซ็ตข้อมูลจำลอง และปีการศึกษาและภาคเรียนปัจจุบันที่หน้าอื่นอ่านไปใช้ |
| `layout-compat.css` | ปรับสไตล์ให้ sidebar และ header แสดงผลถูกต้องในหน้าโมดูล grading ซึ่งใช้ stylesheet ของตัวเอง |
| `demo-autofill.js` | เครื่องมือกรอกข้อมูลอัตโนมัติที่ใช้ตอนอัดวิดีโอสาธิต กด F9 เพื่อกรอกช่องในหน้าที่เปิดอยู่ หรือกด F8 เพื่อเปิดแผงเลือกคำสั่ง เครื่องมือนี้ไม่กดบันทึกหรือส่งแทนผู้ใช้ |
