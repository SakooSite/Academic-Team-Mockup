# curriculum

โมดูลหลักสูตร แต่ละหน้ามีสคริปต์อยู่ในไฟล์ HTML ของตัวเอง

| หน้า | ชื่อในเมนู | เนื้อหา |
|---|---|---|
| `curriculum-management.html` | จัดการหลักสูตร | สร้างหลักสูตรสถานศึกษา จัดแผนการเรียน เพิ่มรายวิชาลงในแผน กำหนดครูผู้สอน และประกาศใช้หลักสูตร นำเข้าและส่งออกข้อมูลได้ |
| `curriculum-structure.html` | โครงสร้างหลักสูตร | แสดงองค์ประกอบของหลักสูตรและหลักคิดหน่วยกิตระดับมัธยม เช่น เรียน 40 ชั่วโมงต่อภาคเรียนได้ 1 หน่วยกิต |
| `course-management.html` | จัดการรายวิชา | เพิ่ม แก้ไข ค้นหา และนำเข้ารายวิชา |

รหัสรายวิชา แผนการเรียน และรหัสครูในหน้านี้ตรงกับข้อมูลจำลองของโมดูลตารางสอน ลิงก์จากหน้าตารางสอนจึงพามาที่แผนการเรียนที่ถูกต้องได้
